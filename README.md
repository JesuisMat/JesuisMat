Growth Manager chez **DAVANT SAS** (Bordeaux) — co-fondateur de **l'Agence Coble** avec mon frère Yannis — et en cours de **MSc Intelligence Artificielle à Epitech** (2025–2027).

Mon approche : pas de code pour le code. Je construis des systèmes qui font gagner du temps à des gens réels, en production, aujourd'hui.

- Pipelines IA **end-to-end** en production (scraping → enrichissement → qualification → email)
- App interne Next.js utilisée par **22 commerciaux** au quotidien
- Sites clients livrés avec i18n, SEO et automatisations n8n intégrés
- Système de **mémoire IA auto-évolutive** qui apprend de chaque session de travail
